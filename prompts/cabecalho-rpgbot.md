# Cabeçalho dos Docs de página bruta (o Claude cria; o usuário cola o conteúdo embaixo)

Criar com `create_file` (contentMimeType text/markdown → vira Google Doc). **Linha em branco entre cada linha**: no
markdown, quebra simples junta tudo num parágrafo só e a URL fica no meio do texto. A URL fica sozinha numa linha,
para o usuário clicar no fim dela e colar.

```
URL:

COLE-A-URL-AQUI

Tipo: <contexto | classe | subclasses | build | magias> — <nome da página>

Edição: D&D 5e 2014 (confirme na página)

Copiado em:

--- CONTEÚDO DO RPGBOT ABAIXO (modo leitura + Ctrl+Shift+V) ---

```
